# 🌸 지유의 먼작귀 3D 루틴 모험 & 마을 꾸미기

9살 지유를 위한 **Three.js 기반 2.5D 데일리 루틴 & 마을 꾸미기 웹앱**입니다.

---

## ✨ 주요 기능
1. **📋 오늘의 루틴 체크**
   - 월요일부터 일요일까지 요일별 맞춤 루틴 실시간 표시
   - 루틴 체크 시마다 **+10P 적립** + 경쾌한 코인 사운드 & 치이카와 리액션
   - 하루 루틴을 모두 완료하면 **대박 보너스 룰렛 기회** 잠금 해제!
2. **🏡 3D 먼작귀 마을 꾸미기 (Three.js)**
   - 3D 체커보드 잔디밭 위에 귀여운 먼작귀 원작 캐릭터들이 입체적으로 서 있는 **2.5D 빌보드** 뷰
   - 마우스 드래그로 360도 회전 및 줌 인/아웃 가능
   - 마을의 캐릭터를 클릭하면 뿅! 점프하며 귀여운 대사 말풍선 출력
   - **동물의 숲 스타일 타일 배치**: 상점에서 구매한 아이템을 원하는 바닥 타일을 클릭해 퐁! 배치 및 회수
3. **🎡 행운의 룰렛**
   - 올클리어 시 도파민 가득한 회전 룰렛으로 보너스 포인트(30P ~ 200P) 획득!
4. **⚙️ 루틴 관리 & 백업 (CRUD)**
   - 언제든지 요일별 루틴 항목 수정, 삭제, 추가 가능
   - 브라우저 LocalStorage에 실시간 자동 저장
   - `[기본 루틴으로 복원]` 및 `[JSON 백업 다운로드/불러오기]` 기능 지원

---

## 🚀 실행 방법 (No-Build)
별도의 `npm install`이나 빌드 과정 없이 바로 실행할 수 있습니다.

### 방법 1. 브라우저에서 바로 열기
* [index.html](file:///C:/KB/OllamaThreeJsDailyRoutine/index.html) 파일을 더블 클릭하여 크롬이나 엣지 등 브라우저로 실행합니다.

### 방법 2. 로컬 웹서버로 실행 (추천)
VS Code의 `Live Server` 확장 또는 파워셸에서 아래 명령어 중 하나를 실행:
```bash
# Python 내장 서버
python -m http.server 8080

# 또는 npx serve
npx serve .
```
브라우저에서 `http://localhost:8080` 으로 접속합니다.
